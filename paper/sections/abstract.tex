\begin{abstract}
We address adaptive parameter control for multi-user satellite free-space-optical (FSO) quantum key distribution (QKD) using subcarrier-intensity-modulation BPSK with dual-threshold direct detection (SIM-BPSK/DT-DD). Extending the geostationary/low-Earth-orbit (GEO/LEO) multi-user architecture, we formulate the joint optimization of the modulation depth, the Alice and per-user dual-threshold coefficients, and the inter-user exclusion ratio as a constrained nonconvex problem that couples all $N$ Alice-Bob pairs through a global modulation depth, a closed-form asymmetric exclusion field, and the unauthorized-receiver (URA) and beam-splitting (BSA) security constraints. We solve it by a two-level decomposition, an outer search over the global variables wrapping a mean-field block-coordinate inner solver over the thresholds, whose outer/inner split is exact and which serves as the oracle for a learned two-stage controller. We compare Kolmogorov--Arnold Networks (KAN), regularized multi-layer perceptrons (MLP), and a linear baseline on a five-axis trade-off (accuracy, closed-loop secret-key retention, parameter count, latency, interpretability). Validated against an SGP4-propagated Starlink-density Walker constellation over a Hanoi ground station, the controller delivers a $2.10\times$ secret-key gain and a $3.6\times$ secure pair-time improvement ($18$ vs $5$ secure pair-steps, $N{=}3$ heterogeneous users); on a sparser shell no static parameter choice is secure at all, making adaptation a precondition for operation. KAN uses $3.3\times$ fewer parameters than the MLP at matching key retention and yields a closed-form rule for the dual-threshold coefficient with $R^2 \approx 0.97$.
\end{abstract}
